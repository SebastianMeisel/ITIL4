# IT-Service-Werkstatt – ITIL 4 verstehen und anwenden

Unabhängige, deutschsprachige, barrierearm gestaltete Web-Lernanwendung auf Basis der **Themenauswahl** des Repositories [SebastianMeisel/ITIL4](https://github.com/SebastianMeisel/ITIL4). Die Texte, Quizfragen und der fiktive Schulfall sind neu erstellt; PDF-Folien, fremde Grafiken und offizielle Prüfungsfragen werden nicht übernommen.

## Start

`lernwerkstatt/index.html` im Browser öffnen (keine Installation oder Internetverbindung erforderlich). Optional im Ordner `lernwerkstatt` einen lokalen Server starten: `python3 -m http.server 8000`, dann `http://localhost:8000` öffnen.

## Inhalte

Grundbegriffe und Wertschöpfung, vier Dimensionen, sieben Leitprinzipien, sechs Aktivitäten der Service Value Chain, ausgewählte Management Practices und kontinuierliche Verbesserung. Ein fiktiver WLAN-Service führt von angeleiteten Entscheidungen zu einem eigenständigen Entscheidungspapier. Als zusätzlicher Transfer ist das Backup-/Ransomware-Beispiel aus `CI_Beispiel.org` thematisch aufgegriffen.

## Datenschutz und Zugänglichkeit

Keine externen Schriften, Skripte, Bilder, Cookies oder Trackingdienste. Lernantworten bleiben im Browser-`localStorage` und können als Text exportiert oder gelöscht werden. Semantisches HTML, Tastaturbedienung, Skip-Link, Fokuskennzeichnung, responsive Darstellung und Reduced-Motion-Unterstützung. WCAG-Konformität ist nicht formal auditiert.

## Qualitätssicherung

Manuell prüfen: Navigation per Tastatur, Single-Choice-Feedback, Notizen speichern, Seite neu laden, Export, Zurücksetzen, Kontrast in Hell/Dunkel. Fachliche Inhalte sind **keine** offizielle Zertifizierungsvorbereitung; bei Prüfungsvorbereitung die aktuelle PeopleCert-Syllabus-Version heranziehen.
